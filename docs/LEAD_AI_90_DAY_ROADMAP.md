# Lead.AI 90-Day Roadmap

## Goal

Create a credible public product ecosystem and ship the first working client-facing demo.

## Days 1-30: Business Audit Lead Magnet

- Build `lead-ai-business-audit` as the first demo.
- Implement the intake form and scoring rubric.
- Generate a report-ready automation roadmap.
- Add a lead capture CTA and follow-up workflow.
- Add screenshots and a short demo video.
- Use client feedback to refine the scoring categories.

## Days 31-60: Website Chatbot MVP

- Build `lead-ai-website-chatbot` widget shell.
- Add FAQ answering and lead capture flow.
- Add conversation summary and contact handoff.
- Create an embed script demo.
- Add deployment notes and screenshots.
- Connect the chatbot lead output to the audit product narrative.

## Days 61-90: WhatsApp Agent And Lead Scoring

- Build WhatsApp webhook prototype.
- Add Twilio placeholder integration and human handoff rules.
- Implement Lead Scoring API schemas and a deterministic baseline score.
- Add reusable lead summary format.
- Start the Lead.AI Platform dashboard as an aggregator for leads, conversations, scores, and module status.

## Success Criteria

- At least one working demo is public.
- Every active repository has screenshots or a demo placeholder.
- README files clearly explain value in the first 10 seconds.
- Security and responsible AI notes are current.
- Public GitHub profile presents a coherent AI SaaS product company.
